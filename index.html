Estructura Selectiva

📘 Fundamento Teórico

Las estructuras selectivas permiten tomar decisiones en el código. Utilizamos condicionales como if, elif y else para ejecutar bloques de código específicos según se cumpla o no una condición lógica.

Estructura Repetitiva

📘 Fundamento Teórico

Las estructuras repetitivas (bucles) permiten ejecutar un conjunto de instrucciones varias veces. Python utiliza principalmente el bucle for para iterar sobre secuencias y el bucle while para repetir mientras una condición sea verdadera.

  1. 1️⃣ fibonacci.py While Loop
  2. 2️⃣ suma de los numeros naturales.py Algoritmo
